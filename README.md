## 买之前怎么验，哪些坑要提前知道

开通后别急着长期用，先把这几步跑完。

第一步查 ASN。用 ipinfo.io 或 ip.sb 看 IP 的归属，确认指向韩国本土 ISP，而不是云服务商。想看得更细就上 bgp.he.net 对一遍宣告该 IP 段的 ASN。

第二步测解锁。直接登录 Netflix、Disney+ 看 region 显示哪个区，跑一遍 TikTok 看播放数据正不正常。清单上写着能解锁的平台，自己逐个登一遍才算数。

第三步测三网延迟和回程。ping 加 traceroute，电信、联通、移动三个方向分别跑，重点看晚高峰会不会绕路。

第四步跑带宽。speedtest 测一遍，看实测值离套餐标称值差多少。200Mbps 是端口带宽，不代表任何地区任何时段都能跑满。

第五步才轮到所谓的风险分。scamalytics 这类站给出的欺诈评分，第三方测评常拿它当标准，说住宅 IP 通常在 10–25 之间。朝暮数据的官方 FAQ 对此的回应很直接：某些网站的 IP 欺诈值检测并没有评分依据，IP 地址也没有纯净、干净、新老的说法，TikTok 这类公司有自己的 IP 地址库和检测手段。两边口径相反，我的建议是把 ASN 归属当硬指标，评分只当参考，别因为一个数字好看就下单。

换了 IP 之后的效果也得自己盯。新开的机器如果解锁不理想，趁退款窗口内处理掉，比事后换 IP 划算。

## 常见问题

### 原生 IP 和住宅 IP 是一回事吗

不是。原生 IP 只要求 ASN 归属指向韩国本土运营商，可能是机房段；住宅 IP 在这个基础上再要求地址属于家庭宽带段。六六云的双 ISP 系列、丽萨主机的韩国套餐卖的都是两层属性合一，朝暮数据则把原生和住宅分别打标，只有 P 区两个都有。

### IP 有“纯净度”和“欺诈分”这回事吗

行业里没有统一说法。第三方测评习惯用 scamalytics 的评分判断 IP 干不干净，服务商官方则不认这套。朝暮数据的 FAQ 明确写着这类检测没有评分依据。实际影响解锁的是平台自己的 IP 库，所以你测出来的分数再低，也不等于 TikTok 一定给你流量。

### 流量用完了会停机吗

各家规则不一样。WePC 的做法是高速流量用完后降速到 5Mbps，不限量也不停机，对直播比较友好。六六云的商品页没有写明超流量后的处理方式，下单前需要在详情页或工单里确认。丽萨主机的流量套餐超了要按规则处理，不限流量套餐则用带宽换流量。

### 1G 内存能装 Windows 吗

能装，但很难用。丽萨主机的官方说法是 1G 内存跑 Windows 会比较吃力，建议至少选 2G 内存的档位再考虑 Windows。真要长期挂 Windows 桌面，2核2G 是底线。
